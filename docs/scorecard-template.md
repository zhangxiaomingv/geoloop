# AI 认知成绩单 · 月度模板

> 用途：每月用 GEOloop 检测一次自己 → 把报告整理成一篇公开文章（个人站 / 知乎 / 公众号）。
> 效果：个人品牌 + 产品案例 + 复测数据一步到位；**名称、定位、官网口径每篇保持一致**（复制自定位锚点）。
> 做法：`npm run serve` 后访问 `http://localhost:8788`，检测 → 复制报告 → 填入下方 `【 】`。

## 提示

- 分数低时**不要藏**，公开低分 + 下月爬坡的对比才是最好的内容（「从 35 分到 70 分的全过程」比满分成绩更有说服力）。
- 每篇都用同一段「开头/结尾」口径，AI 学到的画像才会清晰稳定。
- 发完 1–2 周后，用 GEOloop 的**文章监测**看这篇有没有被 AI 引用，把结果写进下个月成绩单（闭环）。
